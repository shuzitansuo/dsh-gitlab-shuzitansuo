# GitLab 项目工作台

在 DSH 侧边栏里加一个 GitLab 面板：左边是项目树，展开项目就能看到它的分支和标签，点任意一条在右侧看最近的提交。

## 界面

- **左侧栏**：与禅道插件同一套结构——顶部工具栏（刷新 / 连接设置 / 收起）、筛选框、项目列表、底部版本条。
- **项目 → 分支 / Tag**：点项目展开，下面分 `分支` 和 `Tag` 两组（带数量，组头用分支/Tag 图标，不用展开箭头），展开项目后分支和 Tag **都直接展开**，不用再点第二下；需要时仍可单独收起某一组。
- **右侧 · 活动流**：点左侧项目名，右侧显示这个项目的活动，顶部三个标签 `全部` / `推送事件` / `合并事件`（对应 GitLab 活动页的 All / Push events / Merge events），列表和提交一样按日期分组、左侧竖线串起。每条显示操作人、动作、分支或 Tag 名（或 MR 编号）、提交短 SHA 与标题、相对时间；提交 SHA 和 MR 编号可直接点进 GitLab。
- **右侧 · 引用详情**：点分支或 Tag 后显示名称、是否默认分支 / 受保护、最近提交时间、最后作者、读取到的提交数，以及提交列表——按 GitLab 的时序样式呈现：日期组头（今天 / 昨天 / 具体日期）吸顶，左侧提交图标由上到下的竖线串起来；每条提交带头像、标题、作者与相对时间，右侧是短 SHA（可点进 GitLab），若该提交被打过 Tag，还在 SHA 前显示 Tag 胶囊。
- **跳转**：右上「在 GitLab 打开」直达分支或 Tag 页面；提交短 SHA 直达该提交。
- **项目备注**：鼠标移到项目行上，名称与数字之间会出现铅笔图标（提示「备注」）。点它在原位输入，回车保存、Esc 取消；备注以中文括号跟在项目名后（如 `acme/web-app（本周要发版）`）。备注**只保存在本浏览器的 localStorage**（键 `dsh-gitlab-notes-v1`，按项目完整路径记录），不会写回 GitLab，也不会同步到别的浏览器。
- **当前项目高亮**：左侧正在看活动的那个项目行会高亮，项目多了也能对上是哪一个。
- **分组折叠提示**：分支 / Tag 组头平时显示分支、Tag 图标，鼠标悬停时换成展开/收起箭头，提示这一组可以折叠。
- **全部展开 / 全部收起**：左栏工具栏最左边的按钮，一下摊开当前列表里的所有项目及其分支和 Tag，再点一下全部收起。分支 / Tag 的分支数据按 4 个并发拉取，项目多时不会一次打爆 GitLab。
- **活动通知**：右上角的铃铛。开启后，插件每 30 秒检查一次你所有成员项目的新活动（别人推的也算），有新的就在铃铛上显示未读数，点开是气泡列表（项目、谁、做了什么、提交标题、多久以前），点气泡直接跳到 GitLab 对应提交；列表里可以用开关随时关掉接收，或「全部已读」。侧边栏的插件图标上也会带未读数，面板没打开时也能看到。
- **检查更新**：左栏底部的「检查更新」会对比本机插件目录里的文件（index.js / client.js / lib/*.js / package.json）与**正在运行的版本**是否一致——这个插件是本地目录，没有远端版本源，所以它检查的是「磁盘上的代码是否比你正在用的新」，而不是去联网找新版本。结果有三种：`已是最新`、`有更新`（悬停看变更了哪些文件，以及该刷新页面还是重启 DSH）、`检查失败`。
- **收起左栏**：收起后左栏变成 40px 竖条；中间分隔条可拖动（200–560px），也支持键盘左右方向键。宽度与折叠状态记在浏览器本地。

## 连接

1. 第一次打开面板，右侧显示「连接你的 GitLab」。
2. 填实例地址（如 `http://gitlab.example.com`，不要带结尾斜杠）和个人访问令牌（`read_api` 即可）。
3. 保存后立即校验并拉取项目列表；之后可随时点左栏顶部的链接图标改设置。

令牌与配置：

- 令牌只从浏览器发到本机 DSH Host，页面里不保存令牌。
- Host 侧写进 DSH 凭据库的 `DSH_GITLAB_TOKEN`；当前 profile 没有凭据服务时落到 `~/.dsh/gitlab/settings.json`（目录 0700、文件 0600）。
- 令牌输入框留空表示「沿用已保存的令牌」；作废用「清除令牌」。
- 插件配置文件里不写令牌。

保存的规则（由 Host 强制，不是只靠界面）：

- **先校验再落盘**：地址或令牌不通过校验时，原来能用的配置不会被覆盖。
- **换地址必须重输令牌**：否则会拒绝，避免把已有令牌发到另一个地址。
- 地址只接受 `http://` / `https://`，且不接受 `file:` 等协议。
- 明文 HTTP 时表单里会常驻一条警告；能用 HTTPS 就用 HTTPS。

## 范围与限制

- 只读：不创建分支、不打标签、不发合并请求，也不写任何 GitLab 数据。
- 项目列表来自「我是成员的项目」（`membership=true`），最多前 200 个，按最近活跃排序；列表头会标出「前 200」。左侧筛选框只筛选已加载的项目，不是 GitLab 全局搜索。
- 每个项目的分支、Tag 各最多 300 个，超出时分组计数显示 `300+`。
- 提交和活动都是每页 30 条，列表底部有「加载更多」；「读取 N 条提交」说的是已经读到的条数，不是仓库总提交数。
- Host 侧的 `/gitlab/api` 只接受本机（`127.0.0.1` / `localhost` / `::1`）访问，用其它地址打开 DSH 时这个面板会提示不可用。
- 需要 Host 能直连 GitLab：实例只在 VPN 或内网可达时，先连上对应网络。
- HTTPS 实例的证书要能被 Node 校验通过；自签名证书会报明确的错误提示。请求不跟随重定向，避免令牌被带到别的主机。
- 面板会记住上次看的项目、视图（活动 / 引用详情）、活动筛选项和展开状态，刷新后原样恢复。
- 面板文案目前只有中文。
